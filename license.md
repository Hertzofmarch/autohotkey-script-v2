## 🌐 How To Use

### First Script

1. **Install** AHK v2
2. **Create** a `.ahk` file
3. **Write** a hotkey
4. **Test** with Notepad
5. **Add** a hotstring
6. **Refactor** into a class

### User Tips

- ✅ Always declare `#Requires AutoHotkey v2.0`
- ✅ Use `Send` / `SendText` carefully
- ✅ Handle errors with `try / catch`
- ✅ Use `MsgBox` for debugging
- ✅ Keep scripts modular

---

## 💡 Best Tips

- ✅ Prefer `Map()` over associative pseudo-arrays
- ✅ Use `Func` objects for callbacks
- ✅ Log errors to a file
- ✅ Use `#SingleInstance Force`
- ✅ Version your scripts in Git

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Script won't run** | Confirm v2 installed |
| **v1 code errors** | Run migration guide |
| **Hotkey not firing** | Check #IfWinActive |
| **Hotstring not expanding** | Check trigger syntax |
| **GUI not showing** | Add `Show()` call |
| **Errors silent** | Wrap in `try / catch` |
